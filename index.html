Managed OpenTelemetry backend

Run one OpenTelemetry agent. Query it in Insights.

Enroll the OpenTelemetry agent and the portal manages its config over OpAMP. Metrics, logs and traces land in Insights, where the explorer, dashboards, snapshots and alerting already live. The Prometheus-, Loki- and Tempo-compatible APIs stay open, so a Grafana you already run keeps working.

Start here

The xScaler OpenTelemetry agentRecommended

A standard OpenTelemetry Collector under OpAMP management. You write one block of YAML to enroll it. Every pipeline after that comes from the portal, selected by the agent's labels.

1
Create an enrollment token

Fleet Management → Enrollment. Stamp default labels such as environment and region onto every agent the token enrolls. The token is shown once.

2
Point the agent at OpAMP

The agent registers, then trades the enrollment token for its own credential. Reconnects use that credential.

3
Assign a config template

Label selectors decide which agent runs which pipeline. The portal shows the effective config and the delivery history per agent.

otel-collector-config.yaml
# the only file you edit by hand
extensions:
  opamp:
    server:
      ws:
        endpoint: wss://agents.xscalerlabs.com/v1/opamp
        headers:
          Authorization: "Bearer <enrollment-token>"

service:
  extensions: [opamp]

Prometheus remote_write, Grafana Alloy and the OTel SDKs write to the same endpoints with the same two headers. eBPF instrumentation gets traces without touching your code.

Read your data

InsightsIn the portal

An explorer, dashboards, snapshots and alerting come with the tenant. There is nothing to host and no data source to wire up before the first query.

Metrics
Break a metric down by label and read the result, with no PromQL to write first.
Logs
Filter a stream by label, then open the trace a line belongs to.
Traces
Span tree, critical path and service graph for one request.
Explorer
Several queries at once, each with its own signal, so logs sit beside the metric that raised the question.
Dashboards
Visual panel editor with variables, annotations and exemplars. Grafana JSON imports as-is.
Snapshots
Freeze what is on screen and send the link to whoever is on the call.
Alerting
Alert rules, contact points, notification policies, silences and mute timings.
