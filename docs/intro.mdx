# Run one OpenTelemetry agent. Query it in Insights.

<p>Enroll the OpenTelemetry agent and the portal manages its config over <b>OpAMP</b>.
Metrics, logs and traces land in <b>Insights</b>, where the explorer, dashboards,
snapshots and alerting already live. The Prometheus-, Loki- and Tempo-compatible
APIs stay open, so a Grafana you already run keeps working.</p>

<Section eyebrow="Start here" title="The xScaler OpenTelemetry agent" badge="Recommended">
A standard OpenTelemetry Collector under OpAMP management. You write one block of
YAML to enroll it. Every pipeline after that comes from the portal, selected by
the agent's labels.
</Section>

<SplitPanel steps={
  <Steps>
    <Step n={1} title="Create an enrollment token">
      Fleet Management &rarr; Enrollment. Stamp default labels such as{' '}
      <code>environment</code> and <code>region</code> onto every agent the token
      enrolls. The token is shown once.
    </Step>
    <Step n={2} title="Point the agent at OpAMP">
      The agent registers, then trades the enrollment token for its own
      credential. Reconnects use that credential.
    </Step>
    <Step n={3} title="Assign a config template">
      Label selectors decide which agent runs which pipeline. The portal shows
      the effective config and the delivery history per agent.
    </Step>
  </Steps>
}>

```yaml title="otel-collector-config.yaml"
# the only file you edit by hand
extensions:
  opamp:
    server:
      ws:
        endpoint: wss://agents.xscalerlabs.com/v1/opamp
        headers:
          Authorization: "Bearer <enrollment-token>"

service:
  extensions: [opamp]
```

<Section eyebrow="Read your data" title="Insights" badge="In the portal">
An explorer, dashboards, snapshots and alerting come with the tenant. There is
nothing to host and no data source to wire up before the first query.
</Section>

<HairlineGrid columns={4}>
  <Cell title="Metrics">Break a metric down by label and read the result, with no PromQL to write first.</Cell>
  <Cell title="Logs">Filter a stream by label, then open the trace a line belongs to.</Cell>
  <Cell title="Traces">Span tree, critical path and service graph for one request.</Cell>
  <Cell title="Explorer">Several queries at once, each with its own signal, so logs sit beside the metric that raised the question.</Cell>
  <Cell title="Dashboards">Visual panel editor with variables, annotations and exemplars. Grafana JSON imports as-is.</Cell>
  <Cell title="Snapshots">Freeze what is on screen and send the link to whoever is on the call.</Cell>
  <Cell title="Alerting">Alert rules, contact points, notification policies, silences and mute timings.</Cell>
  <Cell title="Your own Grafana" muted>The Prometheus-, Loki- and Tempo-compatible APIs stay open, so existing dashboards keep reading.</Cell>
</HairlineGrid>
